🎨 3. HOW TO CHANGE COLORS
═══════════════════════════════════════════════════════════════

प्रत्येक HTML file मध्ये हे Colors सापडतील:

  --primary: #6366f1;      ← Main Brand Color (Purple)
  --secondary: #8b5cf6;    ← Accent Color
  --bg: #0f172a;           ← Dark Background
  --bg-light: #1e293b;     ← Card Background
  --text: #e2e8f0;         ← White Text
  --text-muted: #94a3b8;    ← Gray Text

हे Hex Codes (#6366f1) तुमच्या Brand Colors ने Replace करा.

✏️ 4. HOW TO CHANGE APP NAME
═══════════════════════════════════════════════════════════════

खालील Text Search करा आणि Replace करा:

  "Universal PWA"     → तुमच्या ॲपचं नाव
  "universal-pwa"     → तुमच्या ॲपचं Short Name

Files मध्ये Search करा:
  - frontend/index.html
  - backend/manifest.json
  - backend/offline.html
  - frontend/*/index.html
